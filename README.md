# novel-writing

通用长篇小说创作工作流 / Universal Novel Writing Workflow

---

## 这是什么？

适用于所有长篇小说类型的创作 Skill。不绑定具体题材，系统流/穿越文/废土文/仙侠/都市/悬疑均可用。

## 触发场景

| 触发词 | 动作 |
|--------|------|
| "写第X章" | 开始写新章节 |
| "继续写" | 读上一章，继续剧情 |
| "写新章节" | 创建新章节文件 |
| "续写" | 读上一章继续写 |
| "帮我写小说" | 全流程引导 |

## Core Workflow

```
1. 读上一章 → 了解剧情进展
2. 读时间线 → 了解故事 chronology
3. 读角色卡 → 了解人物性格
4. 写章节 → ≥3000字，开头钩子+主线冲突+收尾悬念
5. 更新文件 → 时间线 + 角色卡
```

## 章节结构（≥3000字）

| 部分 | 占比 | 内容 |
|------|------|------|
| 开头 | 10% | 钩子 + 埋1个开放式悬念 |
| 主线 | 70-80% | 每500字一个"新鲜刺激点"（反转/发现/战斗） |
| 收尾 | 10-15% | 结果 + 回扣开头 + 强力收尾 |

## 文件结构

```
skill/
├── SKILL.md              # Skill 主文件
├── README.md             # 本文件
└── references/
    ├── 角色指南.md        # 人物说话方式+微表情
    ├── 世界观指南.md      # 规则体系+环境描写
    └── 剧情指南.md        # 结构模板+伏笔系统
```

## 使用提示

- 写之前先读上一章，保持剧情连贯
- 每章写完更新 `creative-lib/时间线.md`
- 新伏笔标记 `[新]`，回收标记 `[x]`
- 系统语录格式（如有）：「检测到...」「翻译：...」
