# 角色指南

通用角色创作指南，适用于所有长篇小说。

## 基础公式

```
姓名 + 年龄 + 核心欲望 + 最大矛盾 + 说话特点
```

## Character Types

### Protagonist (主角型)

**说话方式**：
- 焦虑时：语速加快，断断续续
- 紧张时：用"……"拖延
- 兴奋时：反而沉默
- 撒谎时：眼神飘移

**允许的口头禅**（根据人物背景自定义）：
- "……我操"（震惊/无奈）
- "问一下"（求助前缓冲）
- 符合人物背景的其他口头禅

**❌ 禁止语**：
- "我明白" / "事情是这样的" / "我觉得可以"
- "没什么"（应用"……"代替）
- "你听我说"（太强势）

**微表情/习惯**：
| 情况 | 表现 |
|------|------|
| 思考时 | 某个手指的小动作 |
| 紧张时 | 咬下唇 / 握拳 |
| 撒谎时 | 眼神往左下飘 |
| 愤怒时 | 语速加快，声音压低 |
| 害怕时 | 后退半步，重心下降 |

---

### Mentor/Elder (智者型)

**说话方式**：
- 简短：能用一个字不用两个
- 直接：不带情绪，但每句有分量
- 冷静：几乎不带情感波动
- 有时会用讽刺

**允许的口头禅**：
- "随你"（做好打算）
- "运气不错"（评价别人时）

**❌ 禁止语**：
- 超过10个字的一句话
- "我觉得"（只陈述事实）
- "你明白吗"（不关心对方）
- 任何安慰性话语

**微表情/习惯**：
| 情况 | 表现 |
|------|------|
| 说话时 | 直视对方眼睛 |
| 不信任时 | 手下意识靠近武器/工具 |
| 思考时 | 沉默，皱眉 |
| 轻微认可时 | 嘴角微微一动 |
| 危险时 | 眼睛不眨，武器已抬 |

---

### Antagonist/Villain (反派型)

**说话方式**：
- 表面热情：笑眯眯，话里有话
- 绵里藏针：夸你的时候也是警告
- 不主动表态，等你先说

**危险信号**：
- 用"年轻人"开头 = 警告
- 说"随你"的时候 = 已做好打算
- 笑的时候眼睛不动

**微表情/习惯**：
- 说话时双手背在身后（控制距离）
- 拍人肩膀 = 控制距离
- 眼神像两口深井，看不见底

## 关系动态

| 关系 | 互动模式 |
|------|----------|
| 师徒 | 教导→考验→放手 |
| 盟友 | 交易→信任→牺牲 |
| 对手 | 试探→交锋→妥协 |
| 情人 | 吸引→误解→突破 |
| 仇人 | 误解→冲突→和解/死亡 |

## 圆形人物 vs 扁平人物

- **圆形人物**：有成长、有矛盾、有多面性
- **扁平人物**：单一动机、象征性、功能性
- 主角必须是圆形人物
- 反派/配角可以是扁平人物，但重要角色至少要有两层动机
