# 剧情指南

Generic plot structure and pacing for serialized web fiction.

## 英雄之旅（12阶段）

| 阶段 | 内容 | 章节占比 |
|------|------|----------|
| 1. 平凡世界 | 主角在正常状态 | 1-10章 |
| 2. 拒绝召唤 | 主角收到冒险邀请但犹豫 | 11-15章 |
| 3. 与智者相遇 | 遇到导师，获得指引 | 16-20章 |
| 4. 跨越门槛 | 进入新世界/开始冒险 | 21-30章 |
| 5. 面临挑战 | 遭遇考验和敌人 | 31-35章 |
| 6. 接近深层洞穴 | 接近核心谜题 | 36-40章 |
| 7. 严峻的考验 | 最艰难的挑战 | 41-50章 |
| 8. 得到嘉奖 | 突破，获得关键线索 | 51-55章 |
| 9. 回归 | 返回，面临新选择 | 56-60章 |
| 10. 重生 | 最终决战 | 61-68章 |
| 11. 大道之巅 | 大结局 | 69-70章 |

## 章节结构（3000字+）

### 开头（10% = 300字）
- 第一句抛出钩子：动作/悬念/反差
- 快速进入剧情，禁止长背景铺垫
- 埋1个开放式悬念

### 主线（70% = 2100字）
- 每500字一个"新鲜刺激点"
- 冲突 → 发现 → 反转 → 再冲突
- 保持紧张感，禁止注水内容
- 至少包含：1次战斗/对峙、1次关键发现、1个角色互动

### 收尾（20% = 600字）
- 目标完成或阶段性结果
- 回扣开头承诺
- 埋下一章悬念
- 强力closing line

## 伏笔系统

### 埋伏笔
- 首次出现标记 `[新]`
- 记录在时间线表格中
- 预计回收章节写"?"

### 回收伏笔
- 标记 `[x]`
- 在时间线表格注明回收描述

### 伏笔类型
| 类型 | 示例 |
|------|------|
| 人物伏笔 | "他说过会回来" → 后文他回来了 |
| 物品伏笔 | "那个盒子先不打开" → 后文打开是关键 |
| 台词伏笔 | "你以后会明白" → 后面果然明白了 |
| 设定伏笔 | "有个传说关于..." → 后文应验 |

## 悬念类型

1. **cliffhanger（章节末）**：危险即将发生，停下
2. **mystery（谜题）**：谁做的？为什么？
3. **question（疑问）**：他是谁？它在哪？
4. **prophecy（预言）**：她说的话会应验

---

## 写作节奏检查

- [ ] 每500字有"新鲜刺激点"？
- [ ] 开头兑现了标题承诺？
- [ ] 全程无"水内容"（每句需满足：推进/悬念/新信息/情绪价值）？
- [ ] 结尾有强力收尾/悬念？
- [ ] 系统语录（如果有）用了正确格式？

---

## 剧情加速器

用于节奏变慢时：
1. **突发事件**：爆炸/袭击/有人倒下
2. **秘密揭露**：发现信件/听到对话
3. **背叛转折**：盟友变敌人
4. **时间跳跃**：直接跳到关键节点

## 常用故事类型模板

### 系统穿越文
- 主角穿越获得游戏系统
- 升级打怪收集资源
- 寻找某人/回到原来的世界
- 核心谜题：系统从哪来？

### 废土求生文
- 末日后的世界
- 幸存者聚居点
- 变异体/异能者
- 核心谜题：灾难怎么发生的？

### 都市异能文
- 现代都市背景
- 隐藏的异能世界
- 组织/门派斗争
- 核心谜题：异能从何而来？
