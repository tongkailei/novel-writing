# 剧情指南

通用剧情结构指南，适用于所有长篇小说。

---

## 章节结构（≥3000字/章）

### 开头（10%）
- 第一句抛出钩子：动作/悬念/反差
- 快速进入剧情，禁止长背景铺垫
- 埋1个开放式悬念

### 主线（70-80%）
- 每500字一个"新鲜刺激点"（反转/发现/战斗）
- 冲突 → 发现 → 反转 → 再冲突
- 保持紧张感，禁止注水内容
- 至少包含：1次冲突/对峙、1次关键发现、1个角色互动

### 收尾（10-15%）
- 目标完成或阶段性结果
- 回扣开头承诺
- 埋下一章悬念
- 强力closing line

---

## 经典结构模型（三幕结构）

| 幕 | 章节范围 | 内容 |
|----|----------|------|
| 第一幕 | 1-30% | 建立世界+主角日常+意外事件+决定冒险 |
| 第二幕 | 30-70% | 遇到挑战+成长+失败+更大危机 |
| 第三幕 | 70-100% | 最终决战+解决核心谜题+结局 |

## 伏笔系统

### 埋伏笔
- 首次出现标记 `[新]`
- 记录在时间线表格中
- 预计回收章节写"?"

### 回收伏笔
- 标记 `[x]`
- 在时间线表格注明回收描述

### 伏笔类型
| 类型 | 示例 |
|------|------|
| 人物伏笔 | "他说过会回来" → 后文他回来了 |
| 物品伏笔 | "那个盒子先不打开" → 后文打开是关键 |
| 台词伏笔 | "你以后会明白" → 后面果然明白了 |
| 设定伏笔 | "有个传说关于..." → 后文应验 |

---

## 悬念类型

1. **cliffhanger（章节末）**：危险即将发生，停下
2. **mystery（谜题）**：谁做的？为什么？
3. **question（疑问）**：他是谁？它在哪？
4. **prophecy（预言）**：她说的话会应验

---

## 写作节奏检查

- [ ] 每500字有"新鲜刺激点"？
- [ ] 开头兑现了标题承诺？
- [ ] 全程无"水内容"（每句需满足：推进/悬念/新信息/情绪价值）？
- [ ] 结尾有强力收尾/悬念？
- [ ] 系统语录（如果有）用了正确格式？

---

## 剧情加速器

用于节奏变慢时：
1. **突发事件**：爆炸/袭击/有人倒下
2. **秘密揭露**：发现信件/听到对话
3. **背叛转折**：盟友变敌人
4. **时间跳跃**：直接跳到关键节点

---

## 常用故事类型

| 类型 | 核心谜题 | 关键元素 |
|------|----------|----------|
| 系统穿越文 | 系统从哪来？ | 游戏面板、升级打怪 |
| 废土求生文 | 灾难怎么发生的？ | 末日、异能、变异体 |
| 都市异能文 | 异能从何而来？ | 现代都市、隐藏世界 |
| 仙侠修真文 | 道的终极是什么？ | 修炼、宗门、飞升 |
| 悬疑推理文 | 真相是什么？ | 线索、反转、推理 |
| 爱情言情文 | 两人能否在一起？ | 误会、成长、相守 |
