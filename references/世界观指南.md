# 世界观指南

通用世界观构建指南，适用于所有长篇小说。

---

## 世界观构建四层模型

| 层次 | 内容 | 示例 |
|------|------|------|
| 第一层 | 物理规则（时间/空间/能量） | 魔法体系、异能等级、科技水平 |
| 第二层 | 社会规则（组织/阶层/货币） | 门派/公司/王国、末日资源体系 |
| 第三层 | 文化规则（语言/风俗/禁忌） | 江湖规矩、家族传统、信仰 |
| 第四层 | 核心谜题（世界的秘密） | 灾难来源、穿越原因、终极目标 |

---

## 等级体系设计

### 通用等级模板

**战斗/能力等级**（适用于异能/修仙/魔法类）：
| 等级 | 名称 | 特征 |
|------|------|------|
| 初阶 | 入门/新手 | 普通人力气，几无特殊能力 |
| 中阶 | 正式/资深 | 明显强于常人，区域有名 |
| 高阶 | 强者/精英 | 一方霸主，稀有存在 |
| 顶级 | 传说/天花板 | 世界顶尖，屈指可数 |

**势力等级**：
| 等级 | 描述 |
|------|------|
| 地方级 | 城镇/村落霸主 |
| 区域级 | 省份/地区掌控 |
| 国家级 | 一国最强 |
| 世界级 | 全球影响力 |

## 环境描写公式

```
[视觉] 颜色 + 形状 + 质感
[听觉] 声音 + 距离 + 方向
[嗅觉] 气味 + 浓淡 + 来源
[触觉] 温度 + 质地 + 疼痛
```

**示例**：
> 空气里弥漫着铁锈和腐烂混合的味道。远处传来什么东西拖行的声音，沉闷而持续。风从废墟间吹过，卷起一片灰尘。天是灰的，像一块脏布。

---

## 战斗/冲突描写要点

1. 先写环境/位置（建立空间感）
2. 敌人出现（外形+威胁感）
3. 主角应对（思考+行动）
4. 结果（代价+收获）

**节奏控制**：
- 激烈战斗：短句，快节奏
- 追逐场景：动词连续，无停顿
- 对峙场景：长短句交替，心理描写
