# 世界观指南

Generic world-building patterns for serialized web fiction.

---

## 末日/废土类

### 时间设定
- 以某个灾难事件为元年起点
- 主角穿越时间点要明确
- 重大事件用「事件名」标注

### 等级体系（示例）

**宿主等级**：
| 等级 | 名称 | 经验需求 |
|------|------|----------|
| LV.1 | 拾荒者 | 0/100 |
| LV.2 | 待解锁 | 100+ |

**异能者等级**：
| 等级 | 描述 |
|------|------|
| E级 | 普通人，稍强于常人 |
| D级 | 正式异能者 |
| C级 | 区域强者 |
| B级 | 未登场 |
| A级 | 未登场 |
| S级 | 顶级存在 |

**变异体等级**：
| 等级 | 描述 |
|------|------|
| E-级 | 最弱，普通武器可杀 |
| E级 | 略强 |
| D级 | 中等威胁 |
| C级 | 区域霸主 |

### 关键地点格式

```
地点名：描述
- 位置：
- 特征：
- 危险等级：
- 关键物品/人物：
```

### 货币/资源体系
- 末日类：末日币、工分、罐头
- 仙侠类：灵石、丹药、法器
- 都市类：声望、流量、金钱

## 穿越者设定模板

```
| 编号 | 状态 | 死因/备注 |
|------|------|----------|
| 001 | 死亡 | 自燃/变异/力竭/自杀/失踪 |
| 002 | 存活 | 主角 |
```

**穿越类型**：
- 时间穿越：从过去到现在
- 维度穿越：从异世界到现实
- 游戏穿越：从游戏到现实

**穿越代价**（可选）：
- 能力过强会自燃
- 每用一次减寿
- 需要特定条件激活

## 环境描写公式

```
[视觉] 颜色 + 形状 + 质感
[听觉] 声音 + 距离 + 方向
[嗅觉] 气味 + 浓淡 + 来源
[触觉] 温度 + 质地 + 疼痛
```

**示例**：
> 空气里弥漫着铁锈和腐烂混合的味道。远处传来什么东西拖行的声音，沉闷而持续。风从废墟间吹过，卷起一片灰尘。天是灰的，像一块脏布。

---

## 战斗描写要点

1. 先写环境/位置（建立空间感）
2. 敌人出现（外形+威胁感）
3. 主角应对（思考+行动）
4. 系统提示（给出数据）
5. 战斗结果（代价+收获）

**节奏控制**：
- 激烈战斗：短句，快节奏
- 追逐场景：动词连续，无停顿
- 对峙场景：长短句交替，心理描写
